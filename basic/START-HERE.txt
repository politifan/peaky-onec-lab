Peaky Minds 1С. Дополнение 26.10.2026

Материалы не содержат платформу, лицензию и готовую информационную базу. Платформа устанавливается с официальной страницы 1С. Basic начинает с новой файловой базы без конфигурации. В Конфигураторе задайте имя/версию и управляемое приложение, сохраните и обновите F7. В Предприятии запишите полную сборку и версию. Копию dt загружают в другую пустую цель, сохраняя источник.

Для полного advanced используйте собственную лицензию разработчика и два прямых клиентских сеанса. Официальный источник: https://v8.1c.ru/platforma/litsenziya-dlya-razrabotchikov/ . Односессионная учебная версия годится для части последовательных упражнений, но не подтверждает конкурентность. Свои фактические параметры заносят в отдельную копию environment.json. Статусы активации и исполнения за ученика не заполняются.

Basic metadata-schema.json и advanced metadata-spec.json — перечень объектов и типов для самостоятельной сборки, а не импорт cf. Объекты создают по мере модулей. Basic: ПММастерская → Товары → Поступление/ОстаткиТоваров → НастройкиТоваров. Advanced: Товары/Склады/Заказ и регистры по спецификации; формы, роли, СКД и расширения — по своим урокам.

В basic native/first-calculation.bsl размещают в общем модуле ПМПримеры (Сервер/Вызов сервера, не глобальный). native/first-form.bsl — модуль управляемой формы собственной внешней обработки с командой Проверить. После обновления базы пример 2×15 выдаёт 30. Самостоятельные функции и обработчики размещаются точно по contracts.json; .bsl не является готовым .epf.

В advanced native/first-query.bsl — пример серверного запроса потребности по ссылке Заказа. A:2,A:3,B:1 даёт A:5,B:1; отдельный заказ не входит. Для исторической цены и движения используйте отдельные контракты. Все 56 native контрактов перенесены в Stepik из native-task-map.json. Python задачи Stepik проверяют только модель алгоритма; они не запускают 1С.

native/configuration-edt — не импортированная и не собранная автором заготовка. В ней намеренные отказы проведения; формы/роли/СКД/расширения не реализованы. Для обязательного маршрута соберите метаданные в Конфигураторе по урокам. Для темы EDT экспортируйте свой работающий проект в формат своей версии EDT. Сохранённый project-status.json не подменяют отчётом о фактическом импорте.

Локальные BSL работы сохраняются как исходник и журнал expected/actual с версией базы. Поля отправки и External Grader не подключены, постоянная персональная проверка не обещается. Рабочий отчёт может быть TXT/Markdown/DOCX. Исторические DOCX редакции 2 остаются справочным чтением; актуальные уточнения — Stepik и этот файл. Реальное исполнение платформы и импорт EDT этой публикацией не заявляются.
